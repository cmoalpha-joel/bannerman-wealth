# Bannerman Wealth Wireframes

Static HTML wireframe microsite for GitHub Pages.

## Deploy

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/root`.
6. Save and wait for the Pages deployment to finish.


After deployment, `index.html` is the homepage. Use `wireframes.html` as the internal wireframe index page.
